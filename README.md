# 2023 산업연관분석 웹앱 · 산업조직론 과제물 1

한국은행 「2023년 산업연관표(연장표)」의 **생산자가격 투입산출표**를 읽고, 산업별 표 검색 및 최종수요 변화에 따른 생산·부가가치·수입 유발효과를 계산하는 정적 웹앱입니다. 웹사이트 자체는 서버 없이 GitHub Pages에서 배포되며 계산은 Pyodide 기반의 브라우저 Python에서 수행됩니다.

## 1. 실행 및 사용 방법

1. 웹사이트를 엽니다.
2. **통합대분류(33)·통합중분류(83)·통합소분류(165)·기본부문(380)** 중 하나를 선택하고 **‘선택한 Excel 불러오기’** 버튼을 누릅니다.
3. ‘거래표 및 계수표 조회’에서 시트 선택 → 행 산업 검색·선택 → 열 항목 검색으로 Excel 내용을 확인합니다. 행과 열의 코드 및 원본 값이 표시됩니다.
4. ‘최종수요 증가 시나리오’에서 산업과 금액(단위: **억원**)을 설정해 ‘시나리오 추가’를 누릅니다. 여러 산업을 합쳐 계산할 수 있습니다.
5. ‘유발효과 계산’을 눌러 생산·부가가치·수입 유발액, 생산유발배율, 산업별 순위와 상세 결과를 확인하고 CSV로 저장합니다.
6. 분류를 바꿀 경우 새 Excel을 불러와야 하며 기존 시나리오는 초기화됩니다.

**주의:** 첫 실행 시 Python 런타임과 numpy·openpyxl을 외부 CDN에서 내려받으므로 인터넷 연결이 필요합니다. 기본부문 380개 자료는 12MB 이상의 Excel 파일과 12개 시트를 읽어 시간이 걸릴 수 있습니다. JavaScript를 차단하는 브라우저에서는 동작하지 않습니다.

### 로컬 실행

프로젝트의 루트 폴더에서 Python이 설치되어 있다면 다음을 실행합니다.

```sh
python -m http.server 8000
```

브라우저에서 `http://localhost:8000/`을 열어 사용합니다. `index.html`을 직접 더블클릭하여 `file://`로 열면 보안 정책 때문에 Excel을 불러오지 못할 수 있습니다.

## 2. 경제학적 분석 방법

투입산출표의 열은 해당 산업의 생산에 투입된 상품(중간재)을, 행은 다른 산업이나 최종수요에 제공한 상품을 나타냅니다. 분석은 국산품 최종수요가 외생적으로 변화한다고 가정합니다.

- 생산유발액: `Δx = L Δf`, 여기서 `L = (I − Aᵈ)⁻¹`
- 수입유발액: `Δm = M Δf`, 여기서 `M = Aᵐ L`
- 부가가치유발액: `Δv = V Δf`, 여기서 `V = diag(v) L`
- 생산유발배율: `sum(Δx) / sum(Δf)`

`Aᵈ`는 국산투입계수, `Aᵐ`는 수입투입계수, `v`는 직접 부가가치율(총투입계수표의 코드 **9690**), `L`·`M`·`V`는 한국은행이 제공한 생산·수입·부가가치유발계수 행렬입니다. 계산 시 원본 엑셀 계수값을 그대로 사용하고, `L`·`M`·`V`와 `Aᵈ`, `Aᵐ`, `v`의 행렬 관계를 확인합니다.

모든 계산 내부 금액은 **백만원**입니다. 사용자 입력 및 결과는 **억원**이므로 1억원 = 100백만원을 적용합니다. 원본 거래표·유발액 표의 값은 백만원, 각종 계수표의 값은 무차원 계수로 표시합니다.

### 예시

통합대분류에서 한 산업의 **국산품 최종수요를 100억원 늘리는 경우**를 가정하면, 해당 산업뿐 아니라 그 산업이 구매하는 중간재를 생산하는 다른 산업의 생산유발액도 계산됩니다. 결과의 생산유발액은 중간재를 포함한 총산출의 변화이므로 GDP 증가액이나 부가가치 증가액과 동일한 개념이 아닙니다.

### 분석의 한계

- 2023년 산업구조 및 고정된 투입계수를 전제로 하는 정태적 분석입니다.
- 가격·생산능력·공급제약·기술의 변화와 정책 효과의 인과관계를 직접 추정하지 않습니다.
- 산업별 최종수요 충격은 **국산품에 대한 추가 수요**라고 가정하며, 실제 수요 증가분의 수입품 대체 여부는 별도로 고려해야 합니다.
- 분류 수준별 결과는 집계 방식에 따라 달라질 수 있습니다.
- 수입유발액에는 원본 한국은행 수입유발계수의 범위와 정의가 그대로 적용됩니다.

## 3. 원본 파일과 프로젝트 구조

```text
index.html          사용자 인터페이스
style.css           디자인 및 반응형 레이아웃
app.js              데이터 불러오기/검색/결과 표시/CSV 다운로드
worker.js           Pyodide 환경 로드, 별도 작업 스레드에서 Python 실행
model.py            엑셀 파싱, 코드 검증, 행렬 검증 및 유발효과 계산
.nojekyll           GitHub Pages에서 Jekyll 처리를 건너뛰기 위한 빈 파일
README.md           사용법과 방법론 설명
data/
  io-2023-large.xlsx    통합대분류 (33)
  io-2023-medium.xlsx   통합중분류 (83)
  io-2023-small.xlsx    통합소분류 (165)
  io-2023-basic.xlsx    기본부문 (380)
```

원본 파일은 업로드된 한국은행 Excel을 **이름만 간결하게 변경**해 보관했습니다. 원자료 값은 수정하지 않았습니다. 각 Excel에는 `A표_총거래표(생산자)`, `A표_수입거래표(생산자)`, `A표_국산거래표(생산자)`, `총투입계수(A)`, `수입투입계수(Am)`, `국산투입계수(Ad)`, `생산유발계수`, `수입유발계수`, `부가가치유발계수`, `최종수요 항목별 ... 유발액` 세 시트까지 모두 **12개 시트**가 포함되어 있습니다.

## 4. GitHub Pages 배포

1. [GitHub](https://github.com/)에 로그인하고 우측 상단 `+` → **New repository**를 선택합니다.
2. 예: `io-2023-analysis`라는 이름의 **Public** 저장소를 생성합니다. **Add a README**는 켜도 됩니다.
3. 이 프로젝트 ZIP을 컴퓨터에서 **압축 해제**합니다. ZIP 자체가 아니라 내부의 `index.html`, `style.css`, `app.js`, `worker.js`, `model.py`, `.nojekyll`, `README.md` 및 **`data/` 폴더 전체**를 GitHub 저장소 최상위에 업로드합니다. 웹 화면 업로드가 폴더 계층을 보존하는지 확인하세요. `.nojekyll` 파일은 Windows에서 숨겨질 수 있습니다.
4. `Commit changes`를 선택합니다.
5. 저장소 **Settings → Pages → Build and deployment**에서 `Deploy from a branch` / `main` / `/(root)` 선택 후 저장합니다.
6. **Actions**에서 배포 결과를 확인한 뒤 `https://사용자명.github.io/io-2023-analysis/`로 접속합니다. 저장소 이름이 다르면 주소도 달라집니다.
7. 페이지가 열리면 **대·중·소·기본부문 각각 1회 데이터 불러오기**, 시트 검색, 예시 시나리오 계산, CSV 다운로드까지 확인하세요.

GitHub Pages 설정 공식 설명: <https://docs.github.com/ko/pages/getting-started-with-github-pages/creating-a-github-pages-site>

## 5. 과제 체크리스트

- [ ] GitHub Pages의 공개 URL에서 화면이 정상 표시된다.
- [ ] 원본 Excel 불러오기 버튼으로 4개 분류 모두 사용할 수 있다.
- [ ] 분류별 12개 시트의 행·열 검색이 가능하다.
- [ ] 거래 금액(백만원), 시나리오 금액 및 결과(억원), 계수(무차원)가 구분된다.
- [ ] 여러 산업을 추가해 유발효과를 계산할 수 있다.
- [ ] 생산유발·부가가치유발·수입유발효과와 산업별 세부 결과가 표시된다.
- [ ] CSV 파일을 내려받을 수 있다.
- [ ] README와 출처·해석상의 주의사항이 표시된다.
- [ ] 원자료 공개 권한과 GitHub 저장소의 공개 범위를 확인했다.
